Сьедобна ли ягода
1. Цель проекта

Целью проекта является разработка системы компьютерного зрения для автоматического распознавания ягод по фотографии с использованием нейронной сети MobileNetV2 и библиотеки TensorFlow.

Система способна классифицировать изображение ягоды и определять её принадлежность к одному из пяти классов:

* Blackberry (ежевика)
* Blueberry (черника)
* Cranberry (клюква)
* Raspberry (малина)
* Strawberry (клубника)

2. Используемый датасет

Для обучения нейронной сети использовался набор изображений ягод, разделённых на пять категорий.
https://www.kaggle.com/datasets/unnamed7/berries333

Структура датасета:

data/

├── blackberry/

├── blueberry/

├── cranberry/

├── raspberry/

└── strawberry/

Каждая папка содержит изображения соответствующего вида ягоды.

Во время загрузки данных TensorFlow автоматически присваивает каждой папке числовую метку:

* blackberry → 0
* blueberry → 1
* cranberry → 2
* raspberry → 3
* strawberry → 4

Для обучения изображения автоматически приводятся к размеру 224×224 пикселя.

Датасет разделяется на:

* 80% изображений для обучения;
* 20% изображений для валидации и оценки качества модели.

4. Принцип работы нейронной сети

Нейронная сеть получает на вход фотографию ягоды.

На первых слоях выделяются простые признаки:

* границы объектов;
* цвета;
* контуры;
* текстуры.

На более глубоких слоях сеть начинает определять сложные характеристики:

* форму ягоды;
* расположение семян;
* цветовые особенности;
* структуру поверхности.

После извлечения признаков они передаются в классификатор.

Последний слой использует функцию Softmax, которая преобразует результат в вероятности принадлежности к каждому классу.
